# Three-resource transition monoid

An exact finite transition monoid generated by opening and closing three independent resources.

The system has nine semantic states—the eight open/closed configurations plus a trap state—and six generators:

```text
open0  close0  open1  close1  open2  close2
```

Each monoid element records a state transition together with a three-component additive delta. Composition is ordinary state-map composition with the second delta pulled back through the first state map.

## Exact census

Independent regeneration from the six generators gives:

- **3,536 distinct summaries**;
- **12 bits** as the minimum index width;
- maximum shortest representative length **8**;
- exact shortest-depth histogram:

```text
0:    1
1:    6
2:   36
3:  145
4:  432
5:  876
6: 1088
7:  776
8:  176
```

The counts sum to 3,536.

[`verify_monoid.py`](verify_monoid.py) reconstructs the monoid directly from the six one-step generators; it does not trust the shipped catalog. It checks the total size, distinctness, reachability, shortest-depth histogram, and radius exactly.

## Four-resource comparison

[`MONOID-CENSUS.json`](MONOID-CENSUS.json) also records the analogous four-resource system at **417,874 summaries** with maximum shortest representative length 13. The independently regenerated theorem in this repository is the three-resource count above.
